# trpc-task-manager

A task manager on Next.js 15 and tRPC 11 that keeps its tasks in memory.

- Use the terms in `GLOSSARY.md`. Read the decisions in `docs/adr/` before changing anything they cover.
- The staging branch is the one `.claude/staging` names.
- Commit subjects are one imperative line. Commits, PR bodies, issues and comments carry no trailers, footers or attribution lines of any kind.
- The repository is public. Every piece of data in it is fictitious: no real names, emails, tokens or local file paths, in code, fixtures, logs or comments.
- Keep it small. The brief asks for something simple that works, so a change that adds a feature the spec doesn't name is out of scope.
